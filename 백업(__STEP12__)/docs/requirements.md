## STEP 1 — 요구사항 분석

### 1.1 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | Micro-Factory Kiosk |
| 목표 | 사용자가 커피/영양 구미를 커스텀하여 구매하는 키오스크 |
| 구현 언어 | Python (.py) |
| 인터페이스 | CLI 우선 개발, 이후 GUI 전환 |
| 제출 형식 | .py 파일 ZIP (CLI 버전) |
| 과목 | 프로그래밍기초 (IC-PBL) |

### 1.2 시나리오 요약

- micro-factory kiosk 공개 입찰 참여
- 차별점: 사용자가 제품을 커스텀 가능
- 목표: 최대 이익을 낼 수 있는 구조 설계
- 채점: 제출 코드 오류 없어야 함, 타 조의 질문에 답변 가능해야 함

### 1.3 제약사항

- 최대 용량 미리 정의
- 함수/클래스 블록 구조로 코딩
- 현금: 100, 500, 1000, 5000, 10000원
- 카드 결제 가능
- 잔액 제공
- 재고 소진 시 사용자에게 알림
- 예상치 못한 예외 없어야 함

### 2.1 커피 커스텀 옵션

| 옵션 그룹 | 선택지 |
|----------|--------|
| 종류 | 아메리카노 / 라떼 / 카푸치노 |
| 크기 | Small / Medium / Large |
| 온도 | HOT / ICE |
| 당도/시럽 | 없음 / 보통 / 많이 |
| 샷 | 1샷 / 2샷 |
| 크림 | 있음 / 없음 (라떼/카푸치노만 활성화) |

### 2.2 영양 구미 커스텀 옵션

| 옵션 그룹 | 선택지 |
|----------|--------|
| 맛 | 딸기 / 포도 / 레몬 |
| 성분/효능 | 비타민C / 오메가3 / 콜라겐 |
| 수량 | 5알 / 10알 / 20알 |
| 패키지 | 낱개 / 파우치 |

### 2.3 관리자 기능 목록

- 재고 보충 (수량 추가)
- 상품 추가 / 삭제
- 가격 변경
- 매출 내역 조회
- 현금 보유량 관리
- 판매 상품 ON/OFF
- 번들 할인 정책 설정
- 인기 상품 우선 노출 (top_n 설정)
- 핫(Hot) 표시 임계값 설정
- 관리자 비밀번호 변경
- 레시피 수정
