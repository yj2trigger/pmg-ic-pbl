## 1. 레이어 구조

```
┌─────────────────────────────────────────────┐
│           Business Logic Layer              │
│  (Product / Cart / Payment / Recipe / ...)  │
│  → View가 무엇인지 절대 모름                  │
│  → optional logger 콜백만 수신               │
└─────────────┬───────────────────────────────┘
              │ 함수 호출
    ┌─────────┴──────────┐
    │                    │
┌───▼──────┐     ┌───────▼──────────────┐
│ CLI View │     │ GUI View             │
│(제출용)  │     │+ CLI Logger (시연용)  │
│ 터미널   │     │ GUI 클릭 → 터미널 출력 │
└──────────┘     └──────────────────────┘
```

logger 콜백 패턴:
- Business Logic 함수는 optional logger 파라미터 수신
- CLI 모드: logger 없음 (터미널 직접 출력)
- GUI 모드: logger가 터미널에 행동 로그 출력, GUI는 결과 반영
