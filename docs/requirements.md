## STEP 1 — 요구사항 분석

### 1.1 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | EDK — Erica Drug King |
| 모듈명 | EDK(Erica drug king) |
| 조 이름 | 안산ic |
| 조원 | 유재준, 송지우, 반영석, 신희찬 |
| 목표 | 증상 선택 기반 일반의약품 정보 제공 키오스크 |
| 구현 언어 | Python (PyQt6 GUI) |
| 인터페이스 | CLI + PyQt6 GUI (--gui 플래그로 전환) |
| 과목 | 프로그래밍기초 (IC-PBL) |

### 1.2 프로젝트 배경 및 가설

소프트웨어융합대학 학생들은 과제, 프로젝트, 야간 학습 등으로 장시간 건물 내에 머무르는 경우가 많으며,
두통·감기·소화불량·피로 등 가벼운 증상 발생 시 빠르게 의약품 정보를 확인하고자 하는 수요가 존재한다.

**가설**: 증상 선택 기반 키오스크를 제공하면 학생들이 일반의약품 정보를 보다 쉽고 직관적으로 탐색할 수 있으며,
무인 환경에서도 편의성과 정보 접근성이 향상될 것이다.

### 1.3 사용자

| 항목 | 내용 |
|------|------|
| 주요 사용자 | 소프트웨어융합대학 기숙사/학관 학생 |
| 역할 구분 | 일반 사용자 / 관리자 |
| 인증 | 관리자 비밀번호 인증 필요 |

## STEP 2 — 확정된 요구사항

### 2.1 핵심 기능 (MVP)

| 기능 | 설명 |
|------|------|
| 증상 선택 | 두통 / 감기 / 소화불량 / 피로 / 외상 등 카테고리 선택 |
| 의약품 추천 | 선택한 증상에 해당하는 일반의약품 목록 표시 |
| 상세 정보 | 의약품명, 효능, 복용법, 주의사항 안내 |
| 응급 분기 | 응급 증상 감지 시 "즉시 병원 방문" 안내 화면으로 분기 |
| 관리자 기능 | 의약품 정보 관리, 재고 관리, 비밀번호 변경 |

### 2.2 증상 카테고리 및 의약품 매핑 (초안)

| 증상 카테고리 | 해당 의약품 예시 |
|-------------|----------------|
| 두통 / 열 | 타이레놀, 이지엔6, 게보린 |
| 감기 (코막힘/인후통) | 판콜에이, 화이투벤, 콜드엔 |
| 소화불량 / 속쓰림 | 훼스탈골드, 겔포스, 노루모 |
| 피로 / 비타민 | 아로나민골드, 비타500, 박카스 |
| 외상 / 상처 | 마데카솔, 후시딘, 밴드 |

### 2.3 화면 흐름

```
[대기 화면]
    ↓ 터치
[증상 선택 화면]
    ↓ 증상 선택
[의약품 목록 화면]  ←→  [응급 안내 화면 (응급 증상 시)]
    ↓ 의약품 선택
[의약품 상세 화면]
    ↓ 확인
[주의사항 안내 화면]
    ↓ 완료
[대기 화면]
```

### 2.4 기존 코드 재활용 전략

기존 Micro-Factory Kiosk의 아키텍처를 그대로 유지하고 도메인만 교체한다.

| 기존 구성요소 | EDK에서의 역할 |
|-------------|--------------|
| `Product` (Coffee, Gummy) | `Medicine` — 의약품 1종 |
| `OptionGroup` / `CustomOption` | `SymptomGroup` / `Symptom` — 증상 카테고리/항목 |
| `Ingredient` (재고) | 의약품 재고 수량 관리 |
| `Cart` | 관심 의약품 선택 목록 (정보 탐색용) |
| `Payment` | 제거 또는 단순화 (정보 제공 서비스이므로 결제 불필요) |
| `KioskController` | 증상→의약품 매핑 로직으로 재활용 |
| `DataManager` | 의약품 데이터 JSON 관리 |
| `gui/screens/` | 화면 흐름에 맞게 교체 |

### 2.5 관리자 기능 목록

- 의약품 정보 추가 / 수정 / 삭제
- 의약품 재고 수량 관리
- 증상 카테고리 설정
- 의약품 표시 ON/OFF
- 관리자 비밀번호 변경
